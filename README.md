# Floor Jumper（酒馆楼层快速跳转）

轻量级 SillyTavern 第三方扩展，入口位于聊天输入框左侧的**魔术棒菜单**，打开独立悬浮窗口，跟随酒馆全局主题配色。

## 功能特性

- **快速定位**：输入楼层号回车直达；支持一键到顶（`#0`）、到底、上一条/下一条用户消息。
- **自动加载历史楼层**：目标楼层未渲染时自动触发酒馆历史消息加载并定位高亮。
- **楼层目录预览**：采用虚拟滚动列表，数千楼也能流畅打开与滚动，关闭窗口时零后台开销。
- **实时筛选与搜索**：支持按全部 / 用户 / 角色 / 书签过滤，支持搜楼层号、角色名、正文与书签备注，支持正序/倒序切换。
- **楼层书签**：支持星标收藏与自定义备注，数据随当前聊天元数据（`chatMetadata`）保存，不同聊天自动隔离。
- **原生主题与适配**：完全使用 SillyTavern 全局 CSS 变量，桌面端支持拖拽并记忆位置，移动端自动适配。

## 安装方式

### 方式一：本地手动安装
将整个 `st-floor-jumper` 文件夹复制到 SillyTavern 目录下的：
```text
SillyTavern/public/scripts/extensions/third-party/st-floor-jumper
```
刷新酒馆页面后，点击输入框左侧的 **魔术棒图标 → 楼层跳转** 即可使用。

### 方式二：通过 Git 仓库安装
将本目录推送到任意 GitHub 仓库后，在酒馆右上角 **扩展（Extensions）→ 安装扩展（Install extension）** 中填入仓库链接即可。
